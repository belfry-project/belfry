=======================
Belfry OpenAPI Schema
=======================

This document describes the OpenAPI 3.0.3 specification for the Belfry API (version v2).

This schema serves as the complete API documentation and contract for interacting programmatically with Belfry, which is used for managing Ansible automation workflows, inventories, credentials, and job execution.

* `Explore the Belfry OpenAPI Schema <explorer.html>`_
* `Download the OpenAPI Schema of the latest Belfry release <https://github.com/belfry-project/belfry/releases/latest/download/schema.json>`_

Each `Belfry release <https://github.com/belfry-project/belfry/releases>`_ has the schema of that version attached as ``schema.json``.
